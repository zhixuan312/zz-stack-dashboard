# The asset generators' one dependency, declared.
#
# `checks/app-icons-rebuilt.ts` and `checks/brand-assets-built.ts` re-run
# `scripts/build-app-icon.py` and `scripts/build-brand-assets.py` and require the second run to
# produce byte-identical output. Both scripts need Pillow, and both said so in their own doc
# comments as an "ambient dependency" — this repository declared none, so the console's gate passed
# on a machine where Pillow happened to be installed and failed on a clean clone. CI is the first
# thing that ever ran it on one.
#
# Pinned exactly, and not as a floor: the checks compare BYTES, and the PNG encoder is Pillow's. A
# different version can re-encode the same master into different bytes, which would read as an
# unreproducible asset rather than as a changed dependency.
Pillow==11.3.0
